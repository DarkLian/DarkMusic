# DarkMusic v3.3.1

## Up Next

- **Queue any song.** The right-hand list has a search box and a **View** button: **Collection** shows what is coming up from the current collection, **All Songs** your whole library. Search filters either view.
- **Double-click** (or Enter) a song there to add it to the end of the queue; dragging still places it exactly.
- **Remove** now takes every checked song, not only the highlighted one.

## Fixes

- **Beveled bars at high bar counts:** with many bars, Classic bars and the sideways Artwork spectrum alternated between striped and flat bars. All bars in a row now share the same shading.

## Compatibility

Existing libraries, playlists, lyrics, Up Next and settings remain compatible. Install **`darkmusic-3.3.1.jar`** with **Minecraft 26.2**, **Java 25**, **Fabric Loader 0.19.5+** and **Fabric API for 26.2**. PiP stays optional and installs through its menu. Each version pins its own PiP package, so existing PiP users are asked to install the matching v3.3.1 package there; settings and permissions are kept. **Do not put the dependency ZIP in `mods`**. Native PiP requires Windows x64; the music player supports Windows, Linux and macOS.
