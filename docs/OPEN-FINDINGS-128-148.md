## Measurements and verification limits

A standalone metadata-only benchmark used 100,000 tracks: construction including normalized keys took **256.1 ms**; median four-query evaluation was **34.7 ms** for the previous concatenation/lowercase expression versus **6.7 ms** with cached keys. This is a warmed JVM microbenchmark, not a Minecraft FPS measurement or a network-library benchmark.

A Windows WGC test with a disposable native window performed **97 resize operations**, reported 96 resizes and delivered 90 valid frames, including **5106×1433**, **2146×3833** and **7666×1073**, without capture/pipe errors. An initial probe was clamped by the window's default maximum size; the final fixture explicitly allowed large windows. This verifies capture/transport, not Minecraft/OpenGL display at those dimensions.

Private real-audio-derived fixtures cover Opus title/artist/album/duration, embedded and missing lyrics, and an actual FFmpeg fractional seek. Deterministic tests cover reset/history, progressing/stalled transfers, worker linkage Errors, inline lyrics, ignored root preferences, fingerprint scratch cleanup and incremental matches, image-brand filtering, Unicode search, transient caches and frame bounds.

Physical slow links, large NAS/FLAC contention, AAC/WebM metadata throughput, real audio-device disconnection, extreme lyric-cache size, interrupted updater execution, other GPUs/Windows builds and native non-Windows PiP remain unverified. Existing v3.0.4 capture-performance results are neither replaced nor remeasured by this work.

## Final verification

`scripts/verify.ps1 -DesktopIntegration` passed **606 tests: 600 passed, six skipped**, with zero failures/errors. Five skips are the pre-existing optional live tool-install/LRCLIB/release-install checks and two unavailable Windows symlink fixtures; the sixth is the POSIX-permissions test on Windows. Hosted POSIX runners exercise that test where supported.

English and Traditional Chinese native lyrics/player/HUD smoke runs passed at fullscreen 1920x1080, configured/effective GUI scale 2, with SmoothFont and existing managed tools. These cover actual private-audio playback, pause/seek/speed, local lyrics, Up Next isolation, progress/spectrum rendering and compact/wide layouts. They do not establish hardware device-disconnection recovery or ultrawide OpenGL display.

One early full attempt used an invalid new Gson/Path fixture and encountered an existing gapless/output-route timeout. The corrected fixture and isolated routing case passed; subsequent full runs passed. No timing assertion was weakened to hide that timeout. IntelliJ formatting, whitespace, workflow lint and 1,624-key English/Traditional Chinese parity passed. Private evidence is under `.local-tools/verification/findings-128-148/`. No original private audio was modified or published.

Configuration formats, network/capture consent, third-party dependencies and the v3.0.4 capture-interval policy are unchanged. Intentional behavior changes are conservative updater/scratch maintenance, source-aware import permissions, better missing-metadata display, normalized search, retained unregistered-root preferences and accepting additional PiP frame shapes within the same byte budget.
