# DarkMusic v2.0.1

## Traditional Chinese localization

- Add Traditional Chinese (Taiwan) translations for all 528 entries in the English catalog.
- Follow Minecraft's selected language. Choose 繁體中文（台灣） in Options → Language.
- Preserve song titles, artist names, filenames, and other user metadata.
- Add regression checks for matching translation keys, formatting placeholders, line breaks, translated component rendering, and packaged language resources.
- Update setup and localization documentation.

## Requirements and files

Minecraft 26.2 · Java 25 · Fabric Loader 0.19.5+ · Fabric API for 26.2. Client installation only.

- `darkmusic-2.0.1.jar`: install this mod.
- `darkmusic-2.0.1-sources.jar`: DarkMusic source archive.
- `darkmusic-2.0.1-third-party-sources.zip`: corresponding sources and notices for bundled libraries.

See the [User Guide](https://github.com/DarkLian/DarkMusic/blob/v2.0.1/docs/USER_GUIDE.md) for setup and usage.
