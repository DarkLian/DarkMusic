# DarkMusic v3.6.3

## Fixes

- A lyric file written just before a metadata edit, rename or audio deletion is now settled first, so the lyric file always stays with its song.
- Download scratch folders left behind by an interrupted session are removed the next time downloads start. Active downloads, other folders and published audio are never touched.

## Compatibility

Install **`darkmusic-3.6.3.jar`** with **Minecraft 26.2**, **Java 25**, **Fabric Loader 0.19.5+** and **Fabric API for 26.2**. Existing libraries, playlists, histories and settings remain supported. PiP and Media Controls remain optional Windows x64 extensions installed through their in-game menus; use the matching v3.6.3 packages. **Do not put extension ZIPs in `mods`**. The music player supports Windows, Linux and macOS.
