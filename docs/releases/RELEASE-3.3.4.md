# DarkMusic v3.3.4

## Spectrum

- **Beveled waves and spikes.** With the Beveled spectrum finish, Smooth Wave, Filled Wave, Spike and Filled Spike now look clearly shaded instead of almost flat. Light follows the curve: rising edges catch the light and falling edges fall into shadow, matching the upper-left light on Bars. Filled Wave and Filled Spike also fade from bright near the edge to shaded at the base.
- **Beveled Rounded Bars.** Rounded Bars now get the same lit left side, shaded right side and slightly darker face as Bars, instead of shading only their rounded ends.

Bars, the Circular HUD and the Flat finish look the same as before.

## Compatibility

Existing libraries, playlists, lyrics, Up Next and settings remain compatible. Install **`darkmusic-3.3.4.jar`** with **Minecraft 26.2**, **Java 25**, **Fabric Loader 0.19.5+** and **Fabric API for 26.2**. PiP stays optional and installs through its menu. Each version pins its own PiP package, so existing PiP users are asked to install the matching v3.3.4 package there; settings and permissions are kept. **Do not put the dependency ZIP in `mods`**. Native PiP requires Windows x64; the music player supports Windows, Linux and macOS.
